# Authorized use

Use SecDesk and the Toolkit only on systems and devices you own or have explicit permission to assess. Native terminals can run powerful external tools; the visible launch acknowledgment applies to that session. SecDesk does not grant authorization, provide a license bypass, silently install tools or start target scans.

Vendor tools enforce their own licensing and may persist data or transmit telemetry according to their configuration. SecDesk's own events are local. Native passwords, commands and terminal output are not added to launch audit records or default reports. Hardware transmission, replay, emulation, BadUSB and GPIO actions remain disabled without the real device protocol and USB identities.
