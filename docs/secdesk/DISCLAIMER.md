# Authorized learning and tool use

Use security tools only on systems, networks and devices you own or have explicit permission to assess. SecDesk does not grant authorization, commercial licenses or elevated capture privileges. It never installs tools or starts scans silently. Vendor installation links open only after a click.

Version, capture permissions, service reachability and license validity are unknown until verified. Missing tools do not prevent the app from opening. Runtime captures are not sandboxes. Firmware commands, RF replay/transmit and BadUSB actions are unavailable until a real protocol and separate visible authorization are supplied.
